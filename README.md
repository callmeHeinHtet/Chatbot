# Rangsit University Library Assistant

An AI-powered chatbot assistant for the Rangsit University Library that helps students and faculty with library-related inquiries.

## Features

- Interactive AI chatbot for library assistance
- Quick links for common queries
- Real-time response system
- Dark/Light theme support
- Responsive design
- Multi-language support (EN/TH)

## Technical Details

- Uses Google's Gemini Pro AI model for natural language processing
- Built with vanilla JavaScript
- Responsive CSS with modern design principles
- Real-time chat interface

## Setup

1. Clone the repository
```bash
git clone https://github.com/yourusername/rsu-library-assistant.git
```

2. Configure API Key
- Get your API key from Google AI Studio
- Update the API key in `js/config.js`

3. Run the application
- Use a local server to serve the files
- Open `index.html` in your browser

## Usage

The chatbot can help with:
- Finding books and resources
- Library hours and services
- Study room bookings
- Online database access
