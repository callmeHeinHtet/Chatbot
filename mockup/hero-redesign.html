What's different · v3 (Risograph)

  1. Bold flat color, not warm cream. Cyan + pink + ink as full-bleed blocks like a riso print, not editorial paper.
  2. No serif anywhere. Funnel Display + Funnel Sans throughout — a typeface family I haven't used elsewhere. Bold uppercase + tight tracking instead of literary italics.
  3. Halftone dot textures + grain noise = riso print feel. Cheap-printed-poster aesthetic that fits campus / student culture.
  4. Stamp + ticket motifs. The "FILED · 04/05/26" rotated stamp, the perforated ticket on the right, the "24 HRS OPEN" black-on-yellow circle — all reference real library checkout culture, not magazine spreads.
  5. Hard shadows, not soft. Every interactive element has a 4–8px solid black drop-shadow that shifts on hover. Punchy and physical, not glassy.
  6. Database grid is a tight-bordered block grid with hover color flips (cyan, pink, yellow). Less catalog-card, more poster grid.
  7. Different from Stay/AungNaingThu — no Fraunces serif, no JetBrains Mono codes, no leader dots, no warm cream. Clean break from the editorial house style.
